# Satish Law Agency - Legal Research Platform UI

This is a modern, responsive frontend implementation for your legal research platform, built without complex frameworks so it can be easily run on any device, including an iPad.

## Contents
- `index.html`: The main dashboard for searching documents, case laws, and bare acts.
- `reader.html`: A highly polished document reader for judgments.
- `assets/styles.css`: Additional custom styles.
- `assets/app.js`: JavaScript for interactivity.

## Key Features Suggested & Implemented:
1. **Split-Screen Reader Mode**: Clean, distraction-free reading of judgments with a sidebar for metadata (Bench, Date, Citations).
2. **AI Summary Integration**: UI placeholders for generating "Ratio Decidendi" using AI.
3. **Citations Matrix**: Shows cases referred, overruled, and subsequent citations.
4. **Dark Mode**: Crucial for lawyers reading long documents on screens.
5. **Smart Entity Tagging**: Acts and Sections are highlighted for quick cross-referencing.

## How to use on iPad:
Since you develop on an iPad, you can open these HTML files directly in any local server app (like Koder, Textastic, or Working Copy) or host them on your Vercel/Blogger setup to preview the UI.
